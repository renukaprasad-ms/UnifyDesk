Location data from Countries States Cities Database by dr5hn and contributors:
https://github.com/dr5hn/countries-states-cities-database

Source snapshot: @countrystatecity/countries-browser 2.0.0.
Database licensed under Open Database License (ODbL) v1.0:
https://opendatacommons.org/licenses/odbl/1-0/

This derived database retains country names/codes/calling codes and state/city
names. It is distributed under the same ODbL license. Rebuild using
`node scripts/generate-locations.mjs` after installing dependencies.
Coverage reflects the source dataset; unlisted locations can be entered manually.
